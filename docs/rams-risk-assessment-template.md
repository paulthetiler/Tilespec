## How to use this assessment
This is a reusable starting point, NOT a site-specific assessment. The appointed competent assessor must inspect/review actual site conditions, identify affected people, add/remove hazards and verify that controls exist before work. Record an initial and residual risk score for each hazard, taking account of severity and likelihood using the project's agreed risk matrix. Do not invent scores in advance. Stop work if risks cannot be controlled.
