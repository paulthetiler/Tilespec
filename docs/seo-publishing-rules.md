# TileSPEC SEO publishing policy
- Preferred origin: https://tilespec.vercel.app until a verified production custom domain is selected; change SITE_URL once when switching.
- Publish only genuinely useful service, regional and location pages. No city/service Cartesian product.
- Each indexable URL must have one unique intent, useful original copy, unique title/H1/description and absolute self-referencing canonical.
- No invented local offices, completed projects, testimonials, staff, certifications or project photos presented as documentary evidence.
- City spokes need independently verifiable local relevance and useful city-specific information, not city-name swaps. Otherwise do not publish.
- Link each spoke to its parent hub, relevant service and authentic case studies; hubs link down to published spokes.
- Redirect alternate hostnames and trailing-slash variants at hosting level. Canonicals are hints, not substitutes for redirects.
- Keep only canonical, indexable URLs in sitemap. Do not put noindex pages in sitemap.
- Editorial review must compare new page text against existing pages for near-duplication; automated similarity is a warning, not a Google threshold.
- Add structured data only where it truthfully describes visible page content.
- Review index coverage and search queries in Search Console before expanding beyond initial hubs.
